On the module is a table for four and two tables for three. Seat a happy cat with each patron and press Submit to solve the module; each seating card has four options that can be cycled using the arrow buttons next to it. Submitting an arrangement where any cats are unhappy or a cat is in two places at once will cause a strike.

Some cats are good friends and will be unhappy if they see each other at seperate tables. Some cats are enemies and will be unhappy to be seated at the same table. Use the number of batteries mod 6 to find the diagram that shows a cat's friends in the small table, likewise for the number of indicators and enemies. If friends and enemies would use the same diagram, shift the one for enemies forward by 1, wrapping around if necessary. Note that the table wraps around, i.e. Cyber is adjacent to Agent M.

Each cat is associated with one of six meows as per the table below, which are randomized per-module out of a pool of 30. The arrow buttons will play the meow associated with each cat as it is displayed. One cat per table will have the wrong meow associated with it. Those cats are required to be seated in those places for a solution to be valid.
